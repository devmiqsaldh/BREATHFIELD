## Arquitetura

O projeto usa MVVM (Model-View-ViewModel):

```
BREATHFIELD/
├── Model/          # Modelos de dados
├── Scene/          # Componentes das funcionalidade 
├── View/           # Interface SwiftUI
├── ViewModel/      # Lógica de negócio
```
